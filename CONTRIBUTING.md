# Contributing

Use Python 3.10+ and a current Node.js release. Install `requirements-dev.txt`, run `python -m unittest discover -s tests -v`, then run the JavaScript syntax checks in the README.

Keep PC cursor/focus untouched. Keep commands constrained to selected browser tabs. Never include profiles, connection codes, cookies, `.venv`, logs or private URLs in commits. Validate untrusted requests, and preserve the trusted-LAN scope.

Before submitting a UI change, check touch input on both Android Chrome and iPhone Safari when available. Describe devices actually tested. Do not claim full compatibility based on syntax checks or mocked tests.

Bug reports should include versions, reproduction steps and sanitized error text. Security issues should be reported privately; see SECURITY.md.
