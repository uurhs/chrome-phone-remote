# Pythonのインストールが不要なWindows版

Windows 10/11（64ビット）向けの `chrome-phone-remote-windows-beta.zip` を使います。PCにPythonやpipを入れる必要はありません。Chromeとスマホ、家庭内LANは必要です。これは試用版で、インストーラーや署名済みアプリではありません。

## 最初の準備

1. 配布されたWindows版ZIPをダウンロードし、右クリックして「すべて展開」します。ZIPを開いたまま実行しないでください。
2. 展開した `ChromePhoneRemote` フォルダを、ドキュメントなど書き込み可能な場所に置きます。`Program Files` は避けてください。後でChromeが拡張機能を読み込むため、このフォルダは移動しないでください。
3. フォルダ内の `ChromePhoneRemote.exe` をダブルクリックします。黒い画面に6桁のコードとスマホ用URLが表示されます。黒い画面は閉じずに置いてください。
4. Windows Defender ファイアウォールに聞かれたら、自宅の**プライベートネットワーク**だけ許可します。公共ネットワークは許可しません。
5. PCのChromeで `chrome://extensions` を開き、「デベロッパー モード」をオンにします。「パッケージ化されていない拡張機能を読み込む」で、展開先の `ChromePhoneRemote/extension` フォルダを選びます。
6. 拡張機能のアイコンを押し、PCの黒い画面の6桁コードを入力して接続します。操作したいYouTube動画などのタブを開いておきます。
7. スマホを同じ家庭内ネットワークにつなぎ、スマホのブラウザの**アドレス欄**にPCで表示されたURLを入力します。スマホでも最初だけ6桁コードを入力します。

以降はEXEを起動し、スマホで同じURLを開きます。登録済み端末は自動で再接続します。操作方法は[詳しい説明書](USER_GUIDE_JA.md)の「ゲーム中の操作」を参照してください。

## 更新・終了・削除

- 終了するときはPCの黒い画面で `Q` → Enter。全端末の登録解除は `R` → Enterです。
- 更新時は終了してから、新しいZIPの内容を**同じフォルダ**へ上書きし、Chromeの拡張機能画面で拡張機能を更新します。`.state` フォルダは残してください。ここに端末の登録情報が保存されます。
- 削除するときはサーバーを終了し、Chromeの拡張機能を削除してから、展開したフォルダを削除します。
- `ChromePhoneRemote.exe` だけを別の場所へ移さないでください。隣の `_internal` フォルダが必要です。

## うまく起動しない場合

- Windowsの警告が出る場合があります。このベータ版はコード署名されていません。**配布元とZIPの中身を確認できない場合は実行しないでください。** 警告を無条件に解除することは勧めません。
- ZIPがWindowsの「ブロック」対象になった場合や会社管理PCでは、管理者のポリシーにより実行できないことがあります。管理者権限での起動は不要です。
- スマホから接続できない場合は、同じ家庭内LAN、PCに表示されたURL、プライベート側ファイアウォール許可を確認してください。ポート転送や公共Wi-Fiでは使わないでください。通信は暗号化されません。
- `8765` 番ポート使用中と出たら、既に起動している黒い画面を終了してください。

ソース版の `start.bat` は従来どおりPCにPythonが必要です。Windows版ZIPでは `ChromePhoneRemote.exe` を起動します。
