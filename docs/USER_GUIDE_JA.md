# はじめての使い方（日本語）

Chrome Phone Remote 0.4.1 beta

## 1. 何ができる？

ゲームを表示したPCで、裏にあるChromeのYouTube音量や再生をスマホから操作します。スマホにアプリをインストールする必要はありません。最初の準備だけPCで行います。

音量バーが変えるのは選んだタブの動画音量です。PC全体・ゲーム・Discordの音量ではありません。音声はPCから流れ続けます。

## 2. 用意するもの

- Windows 10または11のPC
- Google Chrome（最新版を推奨）
- Python 3.10以降
- ブラウザを使えるスマートフォン
- PCとスマホが通信できる家庭内ネットワーク

PCが有線LAN、スマホがWi-Fiでも、同じルーター配下なら利用できます。ゲストWi-Fiは端末間の通信を禁止していることがあります。初回の部品インストールにはインターネットが必要です。

これは試用版のソース配布です。WindowsのインストーラーやChromeウェブストアの拡張機能ではありません。

## 3. ZIPを展開する

1. 配布ページからZIPをダウンロードします。
2. ダウンロードしたZIPを右クリックして「すべて展開」を選びます。
3. 保存先を決めて展開します。例：ドキュメント内の `ChromePhoneRemote`。
4. 展開後の `chrome_phone_remote` フォルダを開きます。
5. `start.bat`、`app.py`、`extension` フォルダが見えることを確認します。

**ZIPを開いたまま実行しないでください。** 拡張機能を追加した後は、このフォルダを移動・削除しないでください。Chromeがその場所からファイルを読み込みます。

## 4. Pythonを準備する（初回のみ）

Pythonが既に入っていれば次へ進めます。

1. [Python公式サイト](https://www.python.org/downloads/)からWindows用のPython 3.10以降をインストールします。
2. インストール画面に「Add Python to PATH」がある場合はチェックを入れます。
3. インストールが終わったら、開いていたコマンド画面を閉じます。

このツールを管理者として実行する必要はありません。

## 5. PC側を起動する

1. `start.bat` をダブルクリックします。
2. 初回は必要な部品を入れるので少し待ちます。`.venv` フォルダが自動作成されます。
3. 黒い画面に、6桁の接続コードと `http://192.168...:8765/` のようなスマホ用URLが出れば起動完了です。
4. 黒い画面は開いたままにしてください。

Windowsのファイアウォール確認が出た場合は、自宅ネットワークであることを確認して**プライベートネットワーク**の通信を許可します。ファイアウォール全体を無効にする必要はありません。

## 6. Chrome拡張機能を追加する（初回のみ）

1. Chromeのアドレスバーに `chrome://extensions` と入力してEnterを押します。
2. 右上の「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. 展開先にある **`extension` フォルダ**を選択します。ZIP本体や親フォルダではありません。
5. 「Chrome Phone Remote Bridge」が一覧に出ます。
6. Chrome右上のパズル型アイコンからこの拡張機能を開きます。ピン留めすると次回から便利です。

この拡張機能はページ操作のために `debugger`、タブ一覧のために `tabs`、接続設定保存のために `storage`、自動再接続のために `alarms` 権限を使います。必要性を理解したうえで追加してください。

## 7. PCとスマホを接続する

1. PCのChromeで、操作したいYouTube動画などのページを開きます。
2. 拡張機能のアイコンを押し、黒い画面の6桁コードを入力して「接続 / Connect」を押します。
3. Chromeにデバッグ開始の通知が出る場合があります。これは接続方法による表示です。
4. スマホを家庭内Wi-Fiにつなぎます。
5. スマホのブラウザで、PCに出ているURLを**アドレス欄**へ入力します。検索欄への検索ではありません。
6. スマホにも同じ6桁コードを入力します。
7. タブを選び、映像や音量バーが表示されれば完了です。

コード入力は初回の登録時だけです。PC側を再起動しても、登録済みのスマホと拡張機能は自動接続します。表示コードが変わっていても再入力は不要です。コードは新しい端末を登録するときに使います。連続で間違えると1分間制限されます。

## 8. ゲーム中の操作

| 操作 | 使い方 |
|---|---|
| 音量 | 下のバーを左右に動かす。±5%で微調整 |
| ミュート | スピーカーボタン。もう一度押すと解除 |
| 再生・一時停止 | ▶ / Ⅱ ボタン |
| 早送り・巻き戻し | +10s / −10s。ライブ動画では制限されることがあります |
| タブ切り替え | 上の一覧から選択。PCのChromeでもそのタブを表示します。Chromeウィンドウを前面へ出す操作は行いません |
| ページのクリック | 映像をタップ |
| ページのスクロール | 「操作: スクロール」で上下にスワイプ |
| 拡大・縮小 | 2本指のピンチ、または＋/−。最大400% |
| 拡大した画面の移動 | 「操作: 画面移動」で1本指ドラッグ |
| 元の倍率 | 倍率表示（例：150%）を押す |
| 文字入力 | 映像内の入力欄をタップ後、下部の文字欄に入力して「入力」 |
| 接続のやり直し | 「再接続 / Reconnect」。必要ならタブを選び直す |

## 9. 音量メインならこの設定

YouTubeタブを選び、映像品質を「音量操作のみ / Audio controls only」にします。映像取得を止めながら音量、ミュート、再生操作を使えます。映像が必要になったら「標準 / Balanced」に戻します。

画質は「軽量 / Low」「標準 / Balanced」「高画質 / High」から選べます。カクつく場合は軽量にしてください。背景タブや最小化によるChrome側の描画制限は、この設定だけでは解消できません。

## 10. 終了・翌日の起動

終了：黒い画面で `Q` → Enter、または `Ctrl+C` を押します。登録情報は保持されます。

翌日：`start.bat` を起動し、同じスマホブラウザで同じURLを開くだけです。拡張機能は自動で接続し直します。Chromeが拡張機能を休止していた場合は最大約1分かかることがあります。すぐ接続したいときは拡張機能を開き、コード欄を空欄にして「接続」を押してください。

登録をすべて解除するには、PCの黒い画面で `R` → Enter を押します。スマホ・拡張機能の登録が無効になり、現在の接続も停止します。再利用時は新しい6桁コードで登録し直します。拡張機能だけを解除する場合は、そのポップアップで「登録解除 / Forget device」を押します。

登録情報は展開先の `.state/registrations.json` に保存します。更新時にこのフォルダを消さないでください。スマホのCookie削除、プライベートブラウズ、PCのIPアドレス変更、長期間の未使用（Cookie保存期間は原則1年）では再登録が必要になる場合があります。

## 11. 更新・削除

0.3.x以前から更新するときは、スマホ・拡張機能を一度だけ登録し直してください。以降は登録が保持されます。

更新前にPC側を停止します。新しいZIPを展開し、前と同じフォルダへ上書きします。`chrome://extensions` にある拡張機能の更新アイコン（丸い矢印）を押し、`start.bat` を起動します。スマホのページも再読み込みします。

別の場所に展開した場合は、古い拡張機能を削除して、新しい `extension` フォルダを読み込んでください。

削除：接続解除 → PC側停止 → Chromeの拡張機能を削除 → 展開フォルダ全体を削除。通常のChrome履歴やログイン情報はこのツールのフォルダには保存しません。古い試作版の `chrome-profile` が残っている場合は、個人情報を含む可能性があるため共有しないでください。

## 12. 困ったとき

| 症状 | 確認すること |
|---|---|
| Pythonが見つからない | Python 3.10以降を入れる。PATHを有効化する |
| 部品のインストールに失敗 | インターネット、プロキシ、PCの管理制限を確認。エラー文を控える |
| 起動が壊れた | PC側を停止して `.venv` のみ削除し、`start.bat` で作り直す |
| スマホでページが開かない | PCの黒い画面、URL、同じLAN、ゲストWi-Fi、プライベート側ファイアウォール許可を確認 |
| URLが127.0.0.1 | PCがネットワークに接続されているか確認し再起動。127.0.0.1はスマホからPCへ接続するアドレスではありません |
| コードが違う | 初回登録・再登録時はPCに表示された現在のコードを入力 |
| 拡張機能が接続されない | 通常のWebページを開いてから接続。会社管理Chromeでは権限が禁止される場合あり |
| 映像が止まる | 品質が「音量操作のみ」ではないか。最小化解除、再接続、同じタブのDevToolsを閉じる |
| 音量が--% | YouTube動画ページと選択タブを確認。動画を一度再生して待つ。更新後は拡張機能も更新 |
| ポート使用中 | 先に開いたツールを閉じる。8765番ポートは1つの起動だけで使用 |
| 接続後にボタンが反応しない | 拡張機能を更新・再接続。スマホ側再読み込み |

不具合報告ではWindows・Chromeのバージョン、スマホ機種・ブラウザ、操作手順、エラー文を書いてください。接続コード、Cookie、私的なタブ名・URLを公開しないでください。

## 13. 利用範囲

信頼できる家庭内LAN専用です。通信はHTTP/WSで暗号化されません。ルーターのポート転送、公衆Wi-Fi、インターネット公開に使わないでください。外部分析サービスへの送信や録画保存は実装していません。固定FPSや全サイト・全ゲームでの動作は保証していません。
